# Abwasser-Rechner 0.8.5

## Dynamische Verfahrensgrafik

- Live-Vorschau in der Anlagenbearbeitung
- Automatischer Aufbau aus Hauptverfahren und gewählten Verfahrensstufen
- Darstellungen für Belebtschlamm, SBR, MBR, Tropfkörper und weitere Verfahren
- Optionale Vorklärung, Fällung, Faulung, Entwässerung und weitergehende Reinigung
- Ruhige Animationen für Wasserfluss, Belüftung, Räumer und Dosierung
- Touch- und Tastaturauswahl einzelner Anlagenbereiche
- Pausierbare Animation und Unterstützung für „Bewegung reduzieren“
- GPS-Speicherfix aus Version 0.8.4.1 bleibt enthalten

Die Verfahrenskonfiguration wird in der bestehenden Anlagenakte gespeichert. Bestehende Anlagen bleiben kompatibel.
