# Release 0.9.2a – Navigations- und Cache-Fix

- App startet nun immer im globalen Bereich „Heute“ beziehungsweise auf der zuletzt geöffneten globalen Seite.
- Home- und Breadcrumb-Home-Schaltflächen führen zu „Heute“ statt zur alten Rechner-Startseite.
- Cache-Busting für CSS und App-JavaScript ergänzt.
- Service Worker auf Network-first aktualisiert, damit neue Deployments nicht wie eine ältere Version erscheinen.
- Produktbibliothek und PDF-Import aus 0.9.2 bleiben vollständig enthalten.
