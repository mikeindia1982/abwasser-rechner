# Release 0.11.0-alpha.4 – Phase 1 Anlagenübersicht

## Neu

- Das interaktive 3D-Fließschema ist jetzt das zentrale Element der Anlagenübersicht.
- Beim Öffnen einer Anlage ist der verfahrenstechnische Aufbau sofort sichtbar.
- Komponenten bleiben anklickbar; Animation und Detailkarte funktionieren direkt in der Übersicht.

## Navigation

- Der separate Navigationspunkt „3D-Schema“ wurde entfernt, um Doppelungen zu vermeiden.
- Alte gespeicherte Verweise auf die Schema-Seite werden automatisch auf „Übersicht“ umgeleitet.

## Kompatibilität

- Bestehende Anlagen-, Besuchs- und Dokumentdaten bleiben unverändert.
- Keine Datenmigration erforderlich.
